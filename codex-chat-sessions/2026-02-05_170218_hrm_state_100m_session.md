### Objective
Let `h` be the top-tier hidden state and `\hat{x}` the predicted next state. Loss:

L = 1.0 * MSE(\hat{x}, x_{t+1})
  + 0.5 * BCE(\hat{o}, o)
  + 0.2 * MSE(\hat{s}, s)
  + 0.2 * MSE(\hat{e}, e)
  + 0.2 * MSE(\hat{g}, g)

Where:
- `o` = operator multi-label vector.
- `s` = script scalars (encounter acceptability/desirability, option visibility/performability, reaction desirability).
- `e` = ending targets (desirability, acceptability, structural distance, metric distance).
- `g` = world grading vector (non-MC metrics).
